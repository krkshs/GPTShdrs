# История GPTShdrs

## 0.1.1-alpha.2 — 2026-11-24

Исправления по игровым скриншотам Alpha 1 и журналу Minecraft 1.16.5 / OptiFine HD U G8.

- Исправлена причина `Invalid program "deferred" / "composite"`: пакет явно определяет `RGBA16F` для GLSL 1.20, сохраняя токен формата для загрузчика OptiFine.
- Валидатор больше не подставляет `RGBA16F`: отсутствие определения теперь вызывает ошибку компиляции, как в игровом журнале.
- Уменьшены отражение неба и солнечный блик воды; солнечный диск больше не дублируется в отражении. Под укрытиями отражение приблизительно ослабляется по существующей карте солнечных теней.
- Нормали воды соответствуют производной высоты волн без усиления в 2.2 раза. Прозрачность постепенно уменьшается с длиной пути до дна, используется `depthtex1` непрозрачной сцены.
- Вода сохраняет только материал `block.10000`; стекло и лёд не получают водные эффекты.
- Снижены яркость и теплота дневного солнца, яркость горизонта, экспозиция (0.85), насыщенность (1.0) и Bloom (0.04). Нейтральнее цвет окружающего света.
- Добавлен параметр силы отражения воды (0.35 по умолчанию), русская и английская подписи. Все профили восстанавливают новые настройки цвета и воды.
- Сохраняются число проходов, разрешение и число выборок теней. Вода повторно использует один фильтр теней, добавлены выборка и копирование непрозрачной глубины.
- Обновлены три README и маршрут повторного теста. Версия: `0.1.1-alpha.2`.

Статус: исправления проверяются компиляцией GLSL и сборкой. Загрузка, картинка и FPS этой версии требуют нового игрового теста на RTX 3050 Laptop 4 ГБ / Core i5-12450H / 16 ГБ ОЗУ.

## 0.1.0-alpha.1 — 2026-11-24

Первая основа для Minecraft Java 1.16.5 / OptiFine.

- GLSL 1.20, общие библиотеки и программы геометрии, теней, воды и постобработки.
- Фильтрованные тени солнца/луны, линейное освещение и тёплый свет блоков.
- SSAO, процедурное небо, закат, звёзды, атмосферный и подводный туман.
- Волны воды, отражение неба, солнечные блики, движение растительности.
- Освещение дождя и слабые блики мокрых поверхностей.
- HDR, Bloom, ACES, FXAA, экспозиция и насыщенность.
- Три профиля качества; русские и английские подписи.
- README на английском, русском и китайском с инструкциями по установке и сборке.
- Уточнён компьютер первого теста: RTX 3050 Laptop 4 ГБ, 16 ГБ ОЗУ, Intel Core i5-12450H.
- Воспроизводимая сборка ZIP, SHA-256 и компиляция/линковка glslang.
- Обычный рендер OptiFine в Незере и Энде.

Статус: альфа для первого игрового теста. Игровая совместимость, внешний вид и производительность требуют проверки пользователем.
