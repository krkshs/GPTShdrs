# Основа проекта

## Цель

GPTShdrs — самостоятельный шейдер для Minecraft Java 1.16.5 с OptiFine, развиваемый по результатам игровых тестов. Целевая видеокарта первого теста: RTX 3050, 4 ГБ. Alpha 1 закладывает освещение, тени, воду и атмосферу.

## Файлы

- `shaders/*.vsh`, `*.fsh` — программы, которые загружает OptiFine.
- `shaders/lib/settings.glsl` — настройки и доступные варианты значений.
- `shaders/lib` — цвет, координаты, освещение, атмосфера, тени, волны и SSAO.
- `shaders/program` — общие реализации геометрии, неба и полноэкранного прохода.
- `shaders/block.properties` — ID воды и растений.
- `shaders/shaders.properties` — параметры OptiFine, профили и меню.
- `shaders/lang` — подписи параметров.
- `shaders/world-1` и `world1` — папки без программ, включающие обычный рендер Незера и Энда.
- `tools` — проверка и сборка; `dist` — архивы, исключённые из Git.

## Рендер

1. **shadow** создаёт карту глубины с отсечением прозрачных пикселей. Ветер совпадает с основным проходом. Вода не отбрасывает непрозрачные тени.
2. **gbuffers** вычисляют линейное освещение и пишут HDR-цвет в `colortex0`, нормаль камеры и уровень света неба в `colortex1`.
3. **deferred** применяет SSAO, туман и процедурное небо к непрозрачной сцене. Близкая геометрия руки исключена из SSAO.
4. **gbuffers_water / hand_water** рисуют прозрачные поверхности поверх сцены. Только материал воды получает волны и отражение неба; стекло и лёд сохраняют текстуры.
5. **composite** выделяет яркие участки и размывает горизонтально в `colortex2`.
6. **composite1** размывает свечение вертикально и добавляет к HDR-сцене.
7. **final** применяет экспозицию, ACES, насыщенность, экранную гамму, FXAA и слабый дизеринг.

| Буфер | Формат | Данные |
| --- | --- | --- |
| colortex0 | RGBA16F | Освещённый линейный HDR-цвет |
| colortex1 | RGBA16F | RGB: нормаль камеры × 0.5 + 0.5; A: свет неба |
| colortex2 | RGBA16F | Горизонтально размытые яркие участки |
| shadowtex0 | Глубина | Геометрия, отбрасывающая тень |

Gbuffers не читают буферы, в которые пишут. Полноэкранные проходы используют штатные main/alt-буферы OptiFine. Смешивание нормалей отключено для прозрачной геометрии.

## Перед выпуском

```powershell
py -3 tools/validate_shaders.py --all-options --require-compiler
py -3 tools/build_pack.py
git diff --check
```

Проверка раскрывает include, следит за глубиной и циклами, проверяет пары стадий, меню, профили и папки измерений. GlSlang компилирует и связывает GLSL 1.20 для всех профилей, всех эффектов OFF и каждого эффекта OFF отдельно.

Это статическая проверка. Загрузка в настоящем OptiFine, картинка и FPS подтверждаются тестом по `TESTING.md`. Нельзя отмечать игровой тест пройденным без запуска или отчёта пользователя.

## Git и версии

- Ветки изменений: `codex/<задача>`.
- Версия: `VERSION`; описание: `CHANGELOG.md`.
- Теги альф: `v0.1.0-alpha.1`, `v0.1.0-alpha.2`.
- ZIP и сторонние компиляторы не коммитятся.
- Перед следующей альфой воспроизводим ошибки из отчёта и исправляем их.
- Поддержка 1.16.5 сохраняется; новые функции OpenGL добавляем по необходимости.

Следующие шаги после первого теста: поправить артефакты, настроить контраст/ночную яркость, измерить стоимость эффектов. Затем можно добавить отражения окружения, преломление воды, объёмные облака, PBR и оформление других измерений.
