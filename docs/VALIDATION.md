# Проверка Alpha 2

Дата: 2026-11-24. Версия: 0.1.1-alpha.2.

## Исходный игровой отчёт

Скриншоты пользователя показывают избыточные отражения воды, белые полосы под деревьями и пересвет. Локальный `logs/latest.log` Minecraft 1.16.5 / OptiFine HD U G8 содержит ошибки компиляции `deferred.fsh` и `composite.fsh`: `undefined variable "RGBA16F"`.

В Alpha 1 валидатор подставлял этот enum, из-за чего не обнаруживал ошибку настоящего загрузчика. В Alpha 2 определение находится в самом пакете, а валидатор больше его не добавляет.

## Выполнено локально

- Python 3.10.5, Windows; glslang 16.6.0.
- 23 пары вершинных и фрагментных программ, GLSL 1.20.
- 253 конфигурации с успешной компиляцией и линковкой: LOW, BALANCED, HIGH, все эффекты OFF и каждый из семи переключателей OFF отдельно.
- Дополнительно 253 конфигурации с успешной компиляцией и линковкой в скрытом контексте локального OpenGL-драйвера: Intel UHD Graphics, OpenGL 4.6, драйвер 31.0.101.4887. Это встроенная графика, не RTX 3050 и не запуск игры.
- Старые фрагментные программы `deferred` и `composite` без подставленного enum воспроизвели ошибку `RGBA16F` в том же OpenGL-контексте.
- Проверены структура пакета, вложенные include, параметры меню и профилей, значения по умолчанию, подписи всех опций в двух языках и папки измерений.
- Две независимые сборки дали идентичные байты ZIP. Проверены CRC, расположение shaders в корне, отсутствие Git/компиляторов/кэша и сохранение папок измерений.
- Проверка пробелов и конфликтных маркеров Git пройдена.

Команда компиляции:

```powershell
py -3.10 tools/validate_shaders.py --all-options --require-compiler
```

## Ожидает повторного игрового теста

Загрузка Alpha 2 в Minecraft 1.16.5 / OptiFine, внешний вид и FPS на NVIDIA GeForce RTX 3050 Laptop GPU 4 ГБ с Intel Core i5-12450H и 16 ГБ ОЗУ. Проверки компиляции не запускают игру и не подтверждают картинку или производительность. Проверка встроенного драйвера Intel также не подтверждает работу пакета на NVIDIA.

Число проходов и выборок карты теней сохранено. Один результат фильтра теней используется для воды и её бликов, но добавлены чтение и копирование непрозрачной глубины. Исправно работающие SSAO и Bloom также могут изменить FPS по сравнению с Alpha 1, где соответствующие проходы не компилировались.

Маршрут проверки: [TESTING.md](TESTING.md).

GitHub Actions настроен на проверку и сборку архива при push/PR. Удалённый запуск CI пока не подтверждён.
