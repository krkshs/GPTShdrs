# Проверка Alpha 1

Дата: 2026-11-24. Версия: 0.1.0-alpha.1.

## Выполнено локально

- Python 3.10.5, Windows; glslang 16.6.0.
- 23 пары вершинных и фрагментных программ, GLSL 1.20.
- 253 конфигурации с успешной компиляцией и линковкой: LOW, BALANCED, HIGH, все эффекты OFF и каждый из семи переключателей OFF отдельно.
- Проверены структура пакета, вложенные include, параметры меню и профилей, значения по умолчанию и папки измерений.
- Две независимые сборки дали идентичные байты ZIP. Проверены CRC, расположение shaders в корне, отсутствие Git/компиляторов/кэша и сохранение папок измерений.
- Проверка пробелов и конфликтных маркеров Git пройдена.

Команда компиляции:

```powershell
py -3.10 tools/validate_shaders.py --all-options --require-compiler
```

## Ожидает игрового теста

Загрузка в Minecraft 1.16.5 / OptiFine, внешний вид и FPS на RTX 3050 4 ГБ. Проверка glslang не запускает игру и не проверяет работу загрузчика, OpenGL-драйвера или картинки.

Маршрут проверки: [TESTING.md](TESTING.md).

GitHub Actions настроен на проверку и сборку архива при push/PR. Удалённый запуск CI пока не подтверждён.
