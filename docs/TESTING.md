# Повторный игровой тест — Alpha 2

Начни с Minecraft Java 1.16.5, OptiFine, обычных текстур, профиля BALANCED, 1080p и 10–12 чанков. Дай миру загрузиться 30–60 секунд. Сравни FPS с выключенными шейдерами в той же точке.

Компьютер для теста: NVIDIA GeForce RTX 3050 Laptop GPU, 4 ГБ видеопамяти; 16 ГБ ОЗУ; Intel Core i5-12450H.

## Маршрут на 5–10 минут

| Сцена | Что проверить |
| --- | --- |
| День: поле и лес | Тени под деревьями, объём блоков, отсутствие чёрных поверхностей и пересвета |
| Растения и листья | Небольшое движение, закреплённые корни, совпадение движения с тенями |
| Дом с окнами | Тень внутри, контактное затемнение углов, отсутствие светящихся стен |
| Озеро сверху и под острым углом | Спокойные волны, постепенное скрытие дна с глубиной, сдержанное отражение неба, один солнечный блик без белых полос |
| Вода под деревьями и у берега | Тени остаются читаемыми, отражение слабее, нет светящейся белой поверхности; сравнить с солнечным участком |
| Под водой | Сине-зелёный туман, видимость дна, отсутствие чёрного экрана |
| Стекло, окрашенное стекло, лёд | Исходные текстуры и прозрачность; водяных волн нет |
| Закат | Тёплый свет, плавная смена неба и теней |
| Ночь | Луна и звёзды, читаемость мира, заметность факелов |
| Пещера с факелом и без | Тёплый свет, тёмная атмосфера, отсутствие солнца под землёй |
| Дождь | Серый свет, дальний туман, видимые капли |
| Мобы, сундук, рука, зачарованный предмет | Текстуры, подсветка урона, блеск зачарования |
| Ломание блока и частицы | Трещины и частицы не пропадают и не засвечивают мир |
| Незер и Энд, затем обратно | Обычный рендер в этих измерениях, возврат шейдера в обычный мир |

Команды для тестового мира с включёнными читами:

```text
/time set day
/time set sunset
/time set night
/weather rain
/weather clear
```

## FPS

Сравни **OFF → LOW → BALANCED → HIGH** в одной точке. После переключения дождись загрузки мира, запиши диапазон FPS за 15–30 секунд. Отметь VSync и лимит FPS. HIGH — для сравнения, BALANCED — отправная точка.

При шуме/ореолах у краёв выключи SSAO и сравни. При проблемах с тенями сравни с SHADOWS=0. Если FPS низкий, выбери LOW и уменьши дальность прорисовки.

Приложи скриншоты днём, на закате, ночью, у воды и в пещере. При красной ошибке шейдера нужен точный текст и соответствующий фрагмент `logs/latest.log` из папки игры. При чёрном экране сначала выбери шейдеры OFF.
